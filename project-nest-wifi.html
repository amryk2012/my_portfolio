About this project

A MikroTik-based WiFi system designed and deployed for Nest Specialty Coffee. A Node.js/Express backend generates rotating single-use QR credentials, staff have a display for manual codes, and guests see a custom bilingual Arabic/English hotspot login page with full RTL support and brand-consistent styling.

Key features

  • Dual-ISP load balancing via PCC
  • Rotating single-use QR credentials
  • Staff-facing display for manual codes
  • Bilingual Arabic/English login page with RTL support
  • Brand-consistent hotspot styling

My contribution

Designed and deployed the whole system: the network setup, the Node.js backend, and the login portal.
