Claw Machine for EVA Pharma

A claw machine for EVA Pharma that players control from their phones, run by a server I built.

Technologies
UnityNode.jsExpressWebSocketCloudflare Tunnel

About this project

A claw machine built for EVA Pharma. Players scan a QR code on the machine, enter a name, choose a tier, and control the claw from their own phone. A Node.js server connects the phone to the Unity game, keeps the scores, and runs the leaderboard. Only one player plays at a time, and everyone else sees whether the machine is busy or offline.

Key features

  • Phone controller in the browser: arrow pad or joystick, plus a Grab button
  • Join with a name and a tier: Bronze, Silver, Gold, or Platinum
  • Live score and countdown timer on the player's phone
  • One player at a time, with a busy or offline screen for everyone else
  • Final score and leaderboard rank, stored on the server
  • QR code that links to the controller, with a public link through a Cloudflare tunnel
  • Reconnects a player who briefly loses signal, and cancels the game if the machine goes offline
  • A single run.bat starts the server and the game together

My contribution

I built the Node.js server and the phone controller page that run the claw machine. They talk to the Unity game, and replace Firebase for the leaderboard.
