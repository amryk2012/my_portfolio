About this project

A web-deployed multiplayer card game based on the popular Egyptian card game Screw (لعبة سكرو), inspired by YouTuber Yehia Azzam. Players compete to finish with the fewest points, using bluffing and strategy. It is my first 2D card game, built entirely in Unity and published on itch.io.

Key features

  • Web-based multiplayer card game
  • Strategic, points-based gameplay: the lowest score wins
  • Special card rules
  • Bluffing and competitive play
  • Playable in the browser on itch.io

My contribution

Built the game entirely in Unity and deployed it to the web on itch.io. This was my first 2D card game.
